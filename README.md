# ☕ Locha Cafe

> **A coffee shop concept for the crazy coffee lover.**

## 📖 Introduction

As an enthusiastic coffee lover, I've always enjoyed the balance between **bitterness and sweetness**. ☕️

**Locha Cafe** is a fictional coffee shop concept that I'm building as part of my **Full-Stack Development journey**.

The project combines my interest in **web development, UI/UX, and creative content**, while giving me a practical environment to learn how a website evolves from an initial idea into a fully deployed application.

## 🎯 Project Goal

Build a responsive and interactive coffee shop website while learning and applying full-stack development concepts step by step.
